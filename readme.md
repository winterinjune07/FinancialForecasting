# Financial Planner

*Currently a WIP*

### Notes

- Utilizes the Reading/Parsing/Processing parts of the program in [iCal-Analyzer](https://github.com/winterinjune07/iCal-Analyzer)

### Function

It uses the above repository to take calendar data logging shift-based work, hourly pay, and pay periods and turn that into CSV data logging paycheck history and forecast additional checks. It then

- [x] Logs your recurring expenses

- [ ] Takes your current bank balance

- [ ] Asks if if you've pre-paid the bills

- [ ] Calculate a variety of terms(1, 3, and 6 months) ahead to give you the minimum balance, and with that, estimated spending money, for that length term and untill your next paycheck
